# 店頭注文入力ツール プロジェクト

## 完了した要件 (Completed)
- [x] **デバイス対応**: iPad, ノートPCに最適化された1カラムのレスポンシブデザイン。
- [x] **デザイン**: CAGUUU Design Systemの完全適用（Primary Green、LINE Seed JP / ITC Avant Garde Gothic フォントのセルフホスト、フラットUIコンポーネント）。
- [x] **顧客入力**: 氏名、電話番号、メールアドレス（必須）、郵便番号、都道府県（プルダウン）、市区町村・番地、建物名・部屋番号。
- [x] **住所入力のUX最適化（ベストプラクティス）**: 
  - `zipcloud` APIを利用した郵便番号からの自動補完。
  - 日本郵便の郵便番号検索サイトへの導線設置。
  - 電話番号や郵便番号の全角・ハイフン入り入力を自動で半角数字に補正。
- [x] **スタッフ入力**: 購入商品のSKU、数量の動的追加。
- [x] **オプション機能**: SKUごとの「開梱サービス」「組み立てサービス」のチェックボックス。
- [x] **確認・備考機能**: 入力フォーム → 確認画面 → 完了画面 の3ステップ遷移。確認画面でのスタッフ専用備考欄の実装。
- [x] **バックエンド連携**: Google Apps Script (GAS) をWebhookとしたGoogleスプレッドシートへのデータ自動記録（CORS対応、先頭0消失の対策済み）。
